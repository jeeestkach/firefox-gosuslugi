# Расширение КриптоПро для Safari и Chrome (macOS)

Инструкция по установке расширения КриптоПро для подписи в браузере. Подходит для macOS 10.15 Catalina и новее.

## Сначала главное

Подпись в браузере состоит из трёх частей, и **расширение — только третья**:

1. **КриптоПро CSP** — ядро, хранит ключ. Ставится с [cryptopro.ru](https://www.cryptopro.ru/products/csp) (нужна регистрация).
2. **КриптоПро ЭЦП Browser plug-in** — программа-посредник. Ставится с [cryptopro.ru/products/cades/plugin](https://www.cryptopro.ru/products/cades/plugin) (нужна регистрация). **В этом же установщике лежит расширение для Safari.**
3. **Расширение браузера** — «мостик» внутри браузера. Для каждого браузера своё (см. ниже).

Если CSP и плагин ещё не стоят — поставьте их сначала. Установщик на Catalina: правый клик по `.pkg` → «Открыть» → «Открыть» (обойти Gatekeeper).

## Safari

**Скачивать нечего.** Расширение Safari уже входит в установщик плагина. Его надо только включить:

1. Установите КриптоПро ЭЦП Browser plug-in (если ещё не стоит).
2. Откройте **Safari → Настройки (⌘,) → вкладка «Расширения»**.
3. Поставьте галочку у **CryptoPro Extension for CAdES Browser Plug-in**.
4. Если его нет в списке — откройте **Программы → CryptoPro_ECP** и включите расширение там, потом вернитесь в Safari.
5. Перезапустите Safari (⌘Q).

На Catalina максимум Safari 15 — он подойдёт.

## Chrome

Есть два расширения. Какое нужно — зависит от задачи.

### Обычная подпись — новое расширение из магазина

1. Откройте [страницу в Chrome Web Store](https://chromewebstore.google.com/detail/extension-for-cades-brows/pfhgbfnnjiafkhfdkmpiflachepdcjod).
2. Нажмите **«Установить»**.
3. Требуется плагин версии **2.0.15400 или новее** — если подпись не видится, обновите плагин.

### Вход по подписи на ГАС «Правосудие» (ej.sudrf.ru) — старое расширение

Сайт ej.sudrf.ru написан под **старое** расширение. Новое из магазина пройдёт тест, но на этом сайте вход может не заработать. Старое ставится файлом в режиме разработчика (работает в Chrome версии 138 и ниже, то есть и в Chrome 128 на Catalina):

1. Скачайте файл [iifchhfnnmpdbibifmljnfjhpififfog_main.crx](https://www.cryptopro.ru/sites/default/files/products/cades/extensions/iifchhfnnmpdbibifmljnfjhpififfog_main.crx).
2. Откройте `chrome://extensions/`.
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Перетащите скачанный `.crx` на страницу расширений.
5. Подтвердите установку.

Chrome при каждом запуске будет показывать плашку «Отключить расширения в режиме разработчика» — её можно закрывать.

### Проще всего — Chromium-Gost

Если возиться с расширениями не хочется, есть [Chromium-Gost](https://github.com/deemru/Chromium-Gost/releases) — отдельный браузер с уже встроенными обоими расширениями и поддержкой ГОСТ. Для Intel-Mac на Catalina — файл `chromium-gost-128.0.6613.137-macos-amd64.tar.bz2`. Скачать, распаковать двойным щелчком, перетащить в «Программы», первый запуск — правый клик → «Открыть».

## Проверка

Откройте в нужном браузере тестовую страницу и ответьте «Да» на запрос доступа:

```
https://www.cryptopro.ru/sites/default/files/products/cades/demopage/cades_bes_sample.html
```

Зелёный результат — браузер видит вашу подпись. Для ej.sudrf.ru зелёный тест ещё не гарантирует вход (см. про старое расширение выше).

## Скрипт-помощник

В репозитории есть `download-cryptopro-browser.command` — он показывает, что уже установлено, скачивает то, что качается напрямую (Chromium-Gost, расширение для Firefox), и открывает официальные страницы для остального. Он **ничего не устанавливает и не меняет** в системе.

Запуск на Catalina (Терминал: Программы → Утилиты → Терминал):

```
curl -fsSL https://raw.githubusercontent.com/jeeestkach/firefox-gosuslugi/main/download-cryptopro-browser.command -o ~/Downloads/download-cryptopro-browser.command && bash ~/Downloads/download-cryptopro-browser.command
```

## Что для чего

| Задача | Что нужно |
|---|---|
| Подпись в Safari | плагин + включить расширение в настройках Safari |
| Обычная подпись в Chrome | новое расширение из магазина + плагин 2.0.15400+ |
| Вход по подписи на ej.sudrf.ru | старое расширение (`.crx`, режим разработчика) или Chromium-Gost |
| Подпись без браузера | «Инструменты КриптоПро» → «Создание подписи» → отсоединённая подпись `.sig` |
