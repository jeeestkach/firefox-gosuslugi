# Firefox для Госуслуг (macOS)

Установщик отдельного «чистого» Firefox для Госуслуг, «Картотеки арбитражных дел», ГАС «Правосудие» и банков.

**Зачем.** Браузерные дополнения, особенно VPN-прокси и «скачивалки», могут встраиваться в страницы или пускать трафик через свои серверы. Тогда антифрод Госуслуг отклоняет вход с ошибкой «Не удалось получить данные», даже в приватном окне. Отдельный профиль без дополнений решает эту проблему и не трогает ваш основной Firefox.

## Что делает скрипт

- создаёт отдельный профиль Firefox `gosuslugi-clean` без дополнений, с системными настройками сети (без своих прокси);
- разрешает Firefox доверять сертификатам Минцифры, установленным в «Связку ключей» macOS;
- запрещает дополнениям встраиваться в Госуслуги, kad.arbitr.ru, my.arbitr.ru, ej.sudrf.ru и сайты Сбербанка;
- кладёт на рабочий стол значок **«Firefox Госуслуги»**, который открывает kad.arbitr.ru.

Основной профиль Firefox не меняется. Повторный запуск безопасен.

## Установка

Нужен установленный Firefox в папке «Программы». Проверено для macOS 10.15 Catalina и новее.

Откройте **Программы → Утилиты → Терминал** и выполните:

```
curl -fsSL https://raw.githubusercontent.com/jeeestkach/firefox-gosuslugi/main/install-firefox-gosuslugi.command -o ~/Downloads/install-firefox-gosuslugi.command && bash ~/Downloads/install-firefox-gosuslugi.command
```

Если macOS спросит про доступ Терминала к папке «Рабочий стол», нажмите **OK**.

## Сертификаты Минцифры

Скрипт их не устанавливает. Для сайтов с российскими сертификатами (например, Сбербанк) их нужно установить в «Связку ключей» с параметром «Всегда доверять» по инструкции: https://www.gosuslugi.ru/landing/crt

## Удаление

Удалите значок «Firefox Госуслуги» с рабочего стола и папку
`~/Library/Application Support/Firefox/Profiles/gosuslugi-clean`.
