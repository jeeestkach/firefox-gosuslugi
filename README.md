# Firefox для Госуслуг (macOS)

Установщик отдельного «чистого» профиля Firefox для Госуслуг, «Картотеки арбитражных дел», «Моего арбитра», ГАС «Правосудие» и банков. В профиле из дополнений есть только КриптоПро, поэтому кнопка «Подписать» на сайтах судов работает. Ваш основной Firefox не затрагивается.

## Как установить

Подходит для macOS 10.15 Catalina и новее. Git и инструменты разработчика не нужны: файл скачивается встроенной в macOS командой `curl`.

1. Убедитесь, что Firefox установлен в папке «Программы».
2. Откройте Терминал: **Finder → Программы → Утилиты → Терминал** (или **Cmd + Пробел**, наберите «Терминал», нажмите Enter).
3. Скопируйте команду **целиком**, вставьте в Терминал (**Cmd + V**) и нажмите **Enter**:

   ```
   curl -fsSL https://raw.githubusercontent.com/jeeestkach/firefox-gosuslugi/main/install-firefox-gosuslugi.command -o ~/Downloads/install-firefox-gosuslugi.command && bash ~/Downloads/install-firefox-gosuslugi.command
   ```

4. Установщик покажет отчёт: какие версии Firefox и профили есть, какие в них дополнения, есть ли КриптоПро и ваша электронная подпись. Затем он спросит:
   **«Создать чистый профиль для Госуслуг? [д/Н]»** — напечатайте **д** и нажмите **Enter**.
   Если просто нажать Enter, ничего не изменится (удобно, если нужен только отчёт).
5. Если macOS спросит про доступ Терминала к папке «Рабочий стол», нажмите **OK**.
6. На вопрос **«Запустить „Firefox Госуслуги“ сейчас?»** напечатайте **д** и нажмите **Enter**.

Дальше запускайте значок **«Firefox Госуслуги»** на рабочем столе.

### Если команда выдала ошибку сертификата

На старых macOS встроенный `curl` может не принять сертификат GitHub. Скачайте тот же файл через CDN jsDelivr той же командой, но с другим адресом:

```
curl -fsSL https://cdn.jsdelivr.net/gh/jeeestkach/firefox-gosuslugi@main/install-firefox-gosuslugi.command -o ~/Downloads/install-firefox-gosuslugi.command && bash ~/Downloads/install-firefox-gosuslugi.command
```

### Если не сработало ничего

1. Откройте эту страницу в браузере и нажмите на файл `install-firefox-gosuslugi.command`.
2. Нажмите кнопку **«Download raw file»** (значок скачивания справа вверху).
3. В Терминале напечатайте `bash`, поставьте **пробел**, перетащите скачанный файл в окно Терминала и нажмите **Enter**.

## Зачем это нужно

Браузерные дополнения, особенно VPN-прокси и «скачивалки», могут встраиваться в страницы или пускать трафик через свои серверы. Тогда защита Госуслуг отклоняет вход с ошибкой «Не удалось получить данные», даже в приватном окне. Отдельный профиль, в котором из дополнений есть только КриптоПро, решает эту проблему.

## Как работает установщик

1. **Сначала только отчёт.** Показывает установленные программы Firefox (путь, версия), все профили и их дополнения. Дополнения, которые могут мешать Госуслугам (VPN, прокси, «скачивалки»), помечены ⚠. Также показывает, есть ли плагин КриптоПро и сертификат Минцифры, и **сведения об электронной подписи** (см. ниже).
2. **Затем предложение.** Что будет сделано и что **не** изменится.
3. **Только после вашего «д»** создаёт профиль. По умолчанию ответ «нет», и ничего не меняется.

Если Firefox установлен в нескольких версиях, установщик спросит, какую использовать. Значок будет запускать именно её.

## Отчёт об электронной подписи

Если установлен КриптоПро CSP, установщик только читает его данные и показывает:

- **лицензию КриптоПро на компьютере**: пробная («демо»), бессрочная или истекла;
- по каждому сертификату в хранилище «Личное»:
  - кому выдан и кем;
  - **срок действия** и сколько дней осталось (или что сертификат истёк);
  - **есть ли встроенная лицензия КриптоПро**. Если есть, подпись работает и при «демо»-лицензии;
  - **где лежит закрытый ключ**: на диске этого Mac (путь к папке `…/keys/<пользователь>/xxxxxxxx.000`), на флешке или на токене;
- все папки с ключами на диске.

Ничего не выгружается и не меняется, пароли не запрашиваются.

**Ошибки КриптоПро не мешают установке Firefox.** Отчёт о подписи и установка расширения КриптоПро выполняются отдельно от остального. Если утилита КриптоПро зависла (ждём не дольше 20 секунд), упала или расширение не скачалось, установщик выводит сообщение и продолжает. Профиль и значок создаются в любом случае.

## Что делает (после подтверждения)

- создаёт отдельный профиль `gosuslugi-clean` с системными настройками сети (без своих прокси);
- добавляет в него **только расширение КриптоПро**, чтобы работала кнопка «Подписать» в ГАС «Правосудие» и «Моём арбитре». Расширение скачивается с cryptopro.ru, установщик проверяет, что это именно оно и что оно подписано Mozilla, затем ненадолго запускает Firefox в фоне и **проверяет, что расширение установлено и включено**;
- если окно «Firefox Госуслуги» открыто, закрывает **только его**, чтобы изменения применились. Основной Firefox не закрывается;
- разрешает Firefox доверять сертификатам Минцифры, установленным в «Связку ключей»;
- запрещает дополнениям встраиваться в Госуслуги и сайты Сбербанка. На сайтах судов не запрещает: там нужна КриптоПро;
- кладёт на рабочий стол значок **«Firefox Госуслуги»**, который открывает kad.arbitr.ru.

## Что НЕ изменяется

- программы Firefox: ни одна версия не удаляется и не обновляется;
- другие профили, их дополнения, закладки и настройки;
- список профилей `profiles.ini`: чистый профиль в него не добавляется.

Если папка `gosuslugi-clean` уже занята чем-то другим, установщик остановится и ничего не тронет. Повторный запуск безопасен.

## Что нужно для подписи

- **КриптоПро CSP** и **КриптоПро ЭЦП Browser plug-in** для macOS: https://www.cryptopro.ru/products/cades/plugin
- ваша электронная подпись (сертификат с ключом), установленная в КриптоПро.

При первой подписи на сайте плагин спросит разрешение на доступ. Ответьте «Да».

## Сертификаты Минцифры

Установщик их не ставит. Для сайтов с российскими сертификатами (например, Сбербанк) их нужно установить в «Связку ключей» с параметром «Всегда доверять» по инструкции: https://www.gosuslugi.ru/landing/crt

## Удаление

Удалите значок «Firefox Госуслуги» с рабочего стола и папку
`~/Library/Application Support/Firefox/Profiles/gosuslugi-clean`.
